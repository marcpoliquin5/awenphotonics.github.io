Availability disclosure

The source repository is available under its stated license. There is no paid plan, product license, hosted service, hardware access, customer deployment, support contract, or service-level commitment offered on this site.

What the repository contains

Compiler and runtime

Rust and native compiler/runtime components with automated tests and explicit simulator boundaries.

Typed specifications

Versioned schemas and architecture proposals whose claims are limited to implemented, checked behavior.

Evidence workflows

A required software quality gate and a separate manual hardware benchmark path for reproducible measurement artifacts.
